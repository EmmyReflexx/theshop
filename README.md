## 🎯 About The Project

TheShop is a fully responsive e-commerce website designed to provide a seamless online shopping experience. It includes user authentication (login/signup), a product catalog with filtering and sorting capabilities, a shopping cart, and a user profile section. The design uses a clean blue and white color scheme with modern UI elements and smooth animations.

## ✨ Features

### Core Features
- **User Authentication:** Login and Signup functionality with form validation and a sliding panel design.
- **Product Browsing:** Browse products with sorting (price, newest, rating) and category filters.
- **Shopping Cart:** Add items to cart, adjust quantities, remove items, and view order summary.
- **User Profile:** Personal dashboard with access to order history, wishlist, address book, and account settings.
- **Responsive Design:** Fully responsive layout that works on desktop, tablet, and mobile devices.
- **Mobile Navigation:** Hamburger menu with slide-out navigation for mobile users.

### Additional Features
- **Featured Products:** Highlighted products on the home page.
- **Category Browsing:** Shop by category (Electronics, Fashion, Home & Living, Beauty).
- **Special Offers:** Promotional banners for sales and free shipping.
- **Customer Testimonials:** Social proof section with verified buyer reviews.
- **Newsletter Subscription:** Email signup form for updates.
- **Dark Theme Support:** CSS variables ready for dark mode implementation.
- **Custom Fonts:** Uses LexendDeca for body text and Cinzel for logo/branding.
- **Smooth Animations:** Hover effects, floating elements, and transition animations.

## 🛠 Tech Stack

- **HTML5:** Semantic structure across all pages.
- **CSS3:** Custom properties (variables), Flexbox, CSS Grid, Gradients, Animations, Transitions, and Media Queries.
- **JavaScript:** DOM manipulation, form validation, cart functionality, mobile menu toggle, and product interactions.
- **Font Awesome:** SVG icons for UI elements (search, cart, profile, social media).
- **Google Fonts:** LexendDeca and Cinzel font families.

## 📄 Pages Overview

### 1. Landing Page (`index.html`)
The main entry point showcasing the brand, featured products, and call-to-action buttons.

### 2. Login / Signup Page (`login/login.html`)
A dual-panel authentication page with:
- **Sign In:** Email and password login with "Remember Me" option.
- **Sign Up:** Registration form with name, email, password, and terms agreement.
- **Demo Credentials:** Email: `theshop@domain.com` | Password: `12345678`

### 3. Home Page (`html/index.html`)
The main shopping dashboard featuring:
- Hero section with call-to-action
- Category browsing grid
- Featured products showcase
- Special offers section
- Customer testimonials
- Newsletter subscription

### 4. Products Page (`html/products.html`)
A comprehensive product listing with:
- Sort by options (Featured, Price, Newest, Rating)
- Category filtering
- Product cards with Quick View and Add to Cart
- Product ratings and reviews
- Cart quantity indicator

### 5. Cart Page (`html/cart.html`)
Shopping cart management with:
- Item list with images
- Quantity adjustment (+/- buttons)
- Remove item functionality
- Cart summary (total items, total price)
- Checkout button

### 6. Profile Page (`html/profile.html`)
User account dashboard with:
- Profile image and user details
- Navigation to Personal Information, Order History, Wishlist, Address Book, and Account Settings
